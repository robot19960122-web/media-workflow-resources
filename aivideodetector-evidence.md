# AI video checks: record evidence and uncertainty

Prepared for AI Video Detector with AI assistance. This is an evidence-recording aid, not forensic certification, identity verification or a determination that a person is dishonest.

## Start with access, not a verdict

Record where the video came from, whether the original is available and what the tool could actually read. A public social URL can be inaccessible, deleted or limited. A page that loads is not necessarily a readable video stream. “Unavailable” is not evidence that a clip is authentic or synthetic.

If permitted, use the original file rather than an edited screen recording. Keep provenance notes private if they contain names, private links or tokens. Do not bypass access restrictions to obtain media.

## Separate observations from interpretation

| Question | Observation | Limitation / next step |
| --- | --- | --- |
| Was actual video available? | | |
| Which frames or time ranges were examined? | | |
| Which movement or visual signals were observed? | | |
| Was usable audio present? | | |
| Could compression, editing or missing context matter? | | |
| What independent source could be checked? | | |

Record the tool's likelihood, confidence and stated limitations separately. Do not turn a likelihood into proof, and do not treat confidence in an observation as certainty about a creator's intent. A sampled review cannot establish that every frame is unchanged. A missing score is different from a low score.

## Decide the next verification step

Look for an earlier upload, the original publisher's context or an independent source. Preserve uncertainty when these are unavailable. Do not publish accusations or make high-impact decisions about a person solely from an automated report. A useful outcome can be to stop sharing a clip until better evidence is available.
